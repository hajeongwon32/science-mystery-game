# 호텔 사건 인트로 모듈

`HotelIntro.tsx`가 화면 컴포넌트를 조합하고, `useIntro.ts`가 React 상태와 타이머·키보드·소리를 연결합니다.

| 파일·폴더              | 수정할 내용                                        |
| ---------------------- | -------------------------------------------------- |
| `components/`          | 제목, 자막, 대화창, 인물 소개 등 개별 화면         |
| `content.ts`           | 인물·대사·40초 타임라인                            |
| `state.ts`             | 시작·일시정지·건너뛰기·다시 보기의 진행 규칙       |
| `useIntro.ts`          | 진행 상태와 브라우저 기능 연결, 이벤트·타이머 정리 |
| `audio.ts`             | 빗소리·발걸음·문소리·저음의 Web Audio 합성         |
| `assets.ts`, `assets/` | 이미지 경로, 미리 불러오기, 기존 배경·인물 이미지  |
| `intro.css`            | 화면 배치, 색상, 애니메이션, 반응형 스타일         |

전체 폴더 구조와 읽는 순서는 [개발 안내](../../docs/project-structure.md)를 참고합니다. 실행 명령은 [루트 README](../../README.md)에 있습니다.

배경과 인물은 ImageGen으로 생성했습니다. [생성 프롬프트](../../docs/image-prompts.json)를 참고하세요. 이전 HTML 시안은 로컬 보관 자료이며 저장소에 포함하지 않습니다. 범인·과학 단서·DB·랭킹 구현은 아직 포함하지 않습니다.
